# 내신 지문 트래커

지문 하나마다 거쳐야 하는 **9단계 내신점검시험**과 **변형문제**를 반·학생별로 기록하고 추적하는 웹앱입니다.
설치형 앱(PWA)이라 휴대폰 홈 화면이나 PC에 설치해 앱처럼 쓸 수 있습니다.

> 단어암기 → 내용 T/F(한글) → 내용 T/F(영어) → 빈칸채우기 → 빈칸 유의어 채우기 → 순서익히기 → 서술형 단어채우기 → 서술형 문장쓰기 → 서술형 요약하기 + 변형문제

## 화면

| 탭 | 하는 일 |
|---|---|
| 한눈에 | D-day, 평균 진행률, 시험준비완료 수, 변형 정답률 · 학생×지문 히트맵 · 단계별 반 통과율(병목) · 재시험 대기 목록 |
| 기록 입력 | 지문·단계(또는 변형 유형)를 고르고 반 전체 점수를 한 번에 입력. "아직 통과 못 한 학생만" 필터로 재시험 입력 |
| 학생별 | 지문×단계 표, 다음 할 일, 취약 단계, 변형 유형별 정답률, 최근 기록(삭제 가능) |
| 지문별 | 학생×단계 표 — 반 전체가 막히는 단계 확인 |
| 변형분석 | 학생×변형유형 정답률 |
| 설정 | 반 정보·시험일·변형 목표, 학생 명단, 지문 목록, 9단계 이름과 통과기준, 변형 유형 · CSV/백업 · 공유 서버 연결 |

히트맵이나 표의 칸을 누르면 해당 학생·지문의 9단계 상세가 열리고, 그 자리에서 기록을 추가하거나 지울 수 있습니다.
반은 상단 칩으로 전환하며 개수 제한이 없습니다.

## 판정 규칙

- 단계 **통과**: 그 단계의 최고 정답률(맞은수/총문항)이 통과기준 이상. 재응시 기록이 모두 남고 최고점이 반영됩니다.
- **다음 단계**: 9단계 순서상 아직 통과하지 못한 첫 단계.
- **시험준비완료**: 9단계 모두 통과 + 지문당 변형문제 목표 문항 수 달성.

## 저장 방식

1. **기본: 이 기기에만 저장** — 설정 없이 바로 사용. 기기 간 공유는 백업 파일(.json)로.
2. **공유 서버(Supabase, 무료)** — 여러 사람이 **로그인 없이 링크만으로** 같은 데이터를 보고 고칩니다. 8초마다 자동 동기화.

### 공유 서버 연결 (교사 한 명이 한 번만)

1. [supabase.com](https://supabase.com)에서 새 프로젝트 생성
2. SQL Editor에서 앱 **설정 → 저장·공유 → 처음 한 번 설정하는 법**의 SQL 실행 (앱의 "SQL 복사" 버튼)
3. Project URL과 anon public 키를 앱에 입력 → **연결**
4. 설정에 나오는 **공유 링크**를 함께 쓸 사람에게 전달 — 받은 사람은 링크를 열기만 하면 됩니다

공유 링크를 거치지 않고 이 페이지 주소만으로 모두가 같은 서버를 쓰게 하려면 `config.js`에 URL과 키를 적어 배포하세요.

**주의:** 링크(또는 config.js가 채워진 주소)를 가진 사람은 누구나 모든 데이터를 고치고 지울 수 있습니다. 함께 관리할 선생님에게만 공유하고, 학생에게는 보내지 마세요. 정기적으로 백업 파일을 내려받아 두기를 권합니다.

## 파일

`index.html`(화면·스타일), `app.js`(동작), `config.js`(공유 서버 기본값), `sw.js`(오프라인 캐시), `manifest.webmanifest`·아이콘(앱 설치)
