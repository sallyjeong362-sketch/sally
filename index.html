📘 나만의 영어 단어장

단어·뜻·동의어·반의어를 모아두고, 랜덤으로 섞어 오프라인 시험지를 인쇄해보세요

단어 목록

직접 추가

붙여넣기로 한번에 추가

다른 곳(엑셀, 구글시트, 워드 등)에서 단어 목록을 복사해 아래에 붙여넣으면 자동으로 표 형식으로 분석해드려요.
지원 형식 1 (표 형식, 탭·쉼표·공백 2칸으로 열 구분): 단어 뜻 동의어1/동의어2 반의어1/반의어2
지원 형식 2 (줄바꿈 형식): abandon - 버리다 다음 줄에 동의어: desert, forsake, 반의어: keep, maintain

시험지 옵션

1. 채점할 시험지 고르기

「시험지 만들기」에서 시험지를 만들면 정답과 함께 자동으로 저장돼요. 인쇄물 아래쪽의 시험지 코드와 같은 것을 고르세요.

2. Claude API 키

손글씨 인식에 Anthropic Claude를 사용해요. 키는 이 브라우저에만 저장되고 서버로 보내지 않습니다 (Anthropic API 제외). 키 발급: console.anthropic.com → API Keys

3. 답안지 촬영 / 업로드

학생 답안지를 한 장씩 찍거나, 스캔한 이미지를 한꺼번에 올리세요. 이미지 1장 = 학생 1명으로 처리합니다. 밝은 곳에서 답안지가 화면에 꽉 차도록 찍으면 인식률이 크게 올라가요.
