📘 나만의 영어 단어장

단어·뜻·동의어·반의어를 모아두고, 랜덤으로 섞어 오프라인 시험지를 인쇄해보세요

단어 목록

직접 추가

붙여넣기로 한번에 추가

다른 곳(엑셀, 구글시트, 워드 등)에서 단어 목록을 복사해 아래에 붙여넣으면 자동으로 표 형식으로 분석해드려요.
지원 형식 1 (표 형식, 탭·쉼표·공백 2칸으로 열 구분): 단어 뜻 동의어1/동의어2 반의어1/반의어2
지원 형식 2 (줄바꿈 형식): abandon - 버리다 다음 줄에 동의어: desert, forsake, 반의어: keep, maintain

지문 붙여넣기

영어 지문을 붙여넣으면 흔한 기능어(관사, 전치사 등)와 짧은 단어를 걸러내고 중요해 보이는 단어를 자동으로 뽑아드려요. 내장된 사전에 있는 단어는 동의어·반의어까지 자동으로 채워지고, 사전에 없는 단어는 직접 입력할 수 있게 빈칸으로 남겨둬요. (완벽한 인공지능 분석은 아니라서, 추출 후 목록을 검토하고 원하는 단어만 선택해 추가해주세요.)
